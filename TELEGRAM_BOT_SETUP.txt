Easy FSC E3 Telegram Bot Setup
==============================

Important:
  Revoke the Telegram bot token you pasted into chat and create a fresh token
  in BotFather. Do not put the token in source code.

Recommended free setup:
  Vercel serverless webhook.

Environment variables to add in Vercel:
  TELEGRAM_BOT_TOKEN       Your new BotFather token
  TELEGRAM_WEBHOOK_SECRET  A long random string you choose
  FSC_BOT_MODE             zip
  TELEGRAM_ADMIN_CHAT_ID   Optional: your Telegram numeric chat ID for admin logs
  SUPABASE_URL             Optional: Supabase project URL for permanent stats
  SUPABASE_SECRET_KEY      Optional: Supabase server secret key
                           Legacy alternative: SUPABASE_SERVICE_ROLE_KEY

Optional:
  FSC_BOT_MODE=single
  FSC_BOT_APPID=017C

Admin reader:
  If TELEGRAM_ADMIN_CHAT_ID is set, the bot sends that admin a private log
  every time FSC files are generated. The log includes VIN, mode, file count,
  sent filename, and user chat ID.

  To find your chat ID:
    1. Message the bot from your Telegram account.
    2. Temporarily check the Vercel function logs, or use a Telegram user info
       bot to get your numeric Telegram ID.
    3. Put that number in TELEGRAM_ADMIN_CHAT_ID.

  Admin commands:
    /admin
    /stats

Supabase stats:
  1. Open Supabase SQL Editor.
  2. Run the SQL from supabase_schema.sql.
  3. In Vercel, add:
       SUPABASE_URL
       SUPABASE_SECRET_KEY
     Keep the secret key server-side only. Do not commit it to GitHub.
  4. Redeploy Vercel.
  5. Open:
       https://easy-fsc-e3-bot.vercel.app/api/stats
       https://easy-fsc-e3-bot.vercel.app/

Webhook URL after deploy:
  https://YOUR-VERCEL-PROJECT.vercel.app/telegram

Set the Telegram webhook:
  Replace TOKEN, URL, and SECRET, then run this in PowerShell:

  Invoke-RestMethod `
    -Method Post `
    -Uri "https://api.telegram.org/botTOKEN/setWebhook" `
    -Body @{
      url = "https://YOUR-VERCEL-PROJECT.vercel.app/telegram"
      secret_token = "SECRET"
    }

  Or run:
    .\set_telegram_webhook.ps1

How users use it:
  1. Open Telegram and message @FSCCreateBOT.
  2. Send /start.
  3. Send the 7-character VIN.
  4. The bot sends back FSC files as a ZIP.
     ZIP mode includes the same 21 FSC files as the original fsc_E3.py,
     including 1CR Remote Start:
       017C - DME1
       0180 - DME2
